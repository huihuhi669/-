# 电力故障报告自动生成系统

## 项目说明

基于 Flask + 智谱 AI 大模型开发的电力故障事件分析报告自动生成平台。上传故障相关文档，AI 自动提取故障关键信息，一键生成符合公文格式的 Word 故障分析报告。系统提供 Web 前端操作界面，支持单文档智能生成、分类资料上传、文件管理、历史报告下载等全套功能。

## ✨主要功能

1. 智能生成模式：上传单个故障文档，AI 自动抽取故障字段，快速生成完整报告；
2. 手动分类上传模式：按业务分类上传事件简述、一次设备、二次设备、运行方式等资料；
3. 支持拖拽上传文件；
4. 异步后台任务生成报告，前端实时展示生成进度；
5. 文件管理：查看、下载、删除已上传源文件；
6. 历史报告管理：查看、下载、删除已生成 Word 报告；
7. 对接高德天气 API，自动获取故障地点气象信息；
8. 输出 Word 文档遵循国内公文格式：仿宋正文、黑体标题、首行缩进、1.5 倍行距；
9. 支持解析 txt、docx、csv、json、xlsx 多种故障数据源。

## ⚙配置说明

程序配置位于 backend/app.py，需要配置两项密钥：

1. ZHIPU_API_KEY：智谱开放平台 API Key（必填，调用大模型生成报告）
2. AMAP_KEY：高德天气 API Key（选填，用于获取故障地区气象信息）

> 
> ⚠重要安全提醒：上传代码到 GitHub 前，禁止将真实 API 密钥直接硬编码提交公开仓库。
> 推荐使用系统环境变量读取密钥，参考代码：
> import os
> ZHIPU_API_KEY = os.getenv ("ZHIPU_API_KEY", "")
> AMAP_KEY = os.getenv ("AMAP_KEY", "")

## 🚀快速运行（Windows）

1. 将整个项目解压至本地文件夹；
2. 设置智谱 API 密钥、高德天气密钥；
3. 双击运行【启动项目.bat】；
4. 脚本自动校验 Python、安装依赖，启动后端服务 [http://localhost:5000](http://localhost:5000)；
5. 使用浏览器直接打开 frontend/index.html 文件，即可进入操作界面。

> 
> 注意：前端无需部署 Web 服务器，本地直接打开 html 即可；后端占用 5000 端口，确认端口没有被其他软件占用。

## 📖使用操作流程

### 方式一：智能生成（推荐）

1. 在报告生成页面，点击【选择故障文档】，上传故障记录文档，支持 txt/docx/xlsx/csv/json；
2. 点击【智能生成报告】；
3. 等待进度条执行完毕，报告生成成功后下载 docx 报告。

### 方式二：手动分类上传

1. 展开 “手动分类上传（可选）” 面板；
2. 在下拉框选择对应文件分类：事件简述、故障一次设备信息、故障二次设备信息等；
3. 点击上传区域选择文件，或者直接拖拽文件到上传框；
4. 文件全部上传完成后，点击页面下方【开始生成】；
5. 任务执行完成，下载生成的故障报告。

### 附加功能

1. 文件管理标签页：查看全部已上传源文件，支持下载、删除；
2. 历史报告标签页：查看所有已经生成完成的故障 Word 报告，支持下载、删除。

## ⚠️注意事项

1. API 密钥安全：公开代码仓库禁止提交真实密钥，优先使用环境变量；
2. 端口冲突：后端默认 5000 端口，冲突时修改 app.py 末尾 app.run (port=5000) 更换端口；
3. 文件限制：最大上传文件大小 100MB；旧版.xls 格式不支持，请另存为 xlsx；PDF 解析需要额外安装 pypdf 库；
4. 任务状态存储：任务进度存储在内存，后端重启任务记录会丢失；磁盘上的上传文件、生成报告不会丢失；
5. 录波图分析代码已预留，当前前端没有图片上传入口，可以自行扩展开发。

## 🔧常见问题

1. 运行 bat 提示 Python not found
解决：需要将 Python 添加至系统环境变量 PATH。
2. 前端页面提示请求失败、加载失败
解决：确认后端服务正常启动，浏览器访问[http://localhost:5000](http://localhost:5000)能够返回 JSON；防火墙不要拦截 5000 端口。
3. 报告生成失败
解决：检查智谱 API‑key 是否有效，账户是否有余额；查看后端控制台报错；确认上传文档内容不为空。
4. 中文乱码
解决：bat 脚本已设置 UTF‑8 编码；上传文档建议保存为 UTF‑8 格式。
